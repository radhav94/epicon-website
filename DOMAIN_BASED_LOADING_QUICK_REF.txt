TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Problem: Branch not loading on production
Solution: 
  1. Check domain is exactly www.epicon.in or epicon.in
  2. Check Network tab for cdn.branch.io request
  3. Hard refresh browser (Cmd+Shift+R)

Problem: Branch loading on staging (shouldn't)
Solution:
  1. Check domain name (staging. should not match)
  2. Hard refresh browser
  3. Verify file was deployed

Problem: trackBranchEvent not available
Solution:
  1. Hard refresh browser
  2. Check console for errors
  3. Verify JavaScript is enabled
