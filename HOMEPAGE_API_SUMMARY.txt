QUICK START
═══════════════════════════════════════════════════════════════════════════

1. Login to get user token
2. Call homepage API with user_id and profile_id

GETTING A USER TOKEN
═══════════════════════════════════════════════════════════════════════════

curl -X POST 'https://contentapistg-njsapi.epicon.in/index/users/login' \
  -H 'x-access-auth-token: szQDOyDaxsS0E4qeV1rMfpYBKnSWVESH' \
  -H 'Content-Type: application/json' \
  --data '{"phone_number": "+919876543210", "password": "your_password"}' | jq .

Response will contain:
- token: Use this in Authorization header
- user_id: Use in homepage API call
- profile_id: Use in homepage API call

EXTRACT CONTINUE WATCHING
═══════════════════════════════════════════════════════════════════════════

# Show only continue watching tray
jq '.data.list[] | select(.display_type=="continuewatching")'

# Show continue watching items with progress
jq '.data.list[] | select(.display_type=="continuewatching") | .content[] | {
  title,
  progress: ((.user_duration / .duration * 100) | floor)
}'

# Count continue watching items
jq '.data.list[] | select(.display_type=="continuewatching") | .content | length'

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Issue:              Continue watching not appearing
Cause 1:            User not logged in
Solution:           Add Authorization header with valid token

Cause 2:            Missing user_id and profile_id parameters
Solution:           Add both parameters to query string

Cause 3:            Invalid token
Solution:           Get fresh token by logging in again

Cause 4:            User has no watched content
Solution:           Watch some content first, then check again
